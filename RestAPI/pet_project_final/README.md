
Проект создан для демонстрации умения работать с чистым кодом на Go и может служить основой для реальных сервисов.

Простой RESTful API, разработанный на языке Go. Проект демонстрирует навыки backend-разработки: создание API, обработку запросов,а также работу с данными. Простой, базовый сервер для управления ресурсами (пользователями и их задачами), с поддержкой CRUD-операций.

Основные возможности:
1)Обработка HTTP-запросов с использованием роутера (echo или стандартный net/http)
2)Интеграция с базой данных (PostgreSQL/MySQL или in-memory для простоты)
3)Валидация данных
4)Логирование и обработка ошибок

Технологии:
1)Go (Golang, v1.22+)
2)Echo (или стандартная библиотека net/http) — веб-фреймворк
3)GORM — ORM
4)Validator — валидация (github.com/go-playground/validator)
5)PostgreSQL - СУБД
6)go mod — управление зависимостями
